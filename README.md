# India VCM News Feed

Scheduled, key-free news-intelligence pipeline for **India VCM Explorer** (`indiavcm.com`). It is designed to live in `ProbablyShubham/indiavcm_news` and publish two stable files:

- `news.json` — normalized, filtered, deduplicated and geolocated news items
- `news_meta.json` — source health and feed diagnostics

The main India VCM site fetches these files directly. No redeploy of the project dashboard is required when the news feed refreshes.

## What it does

1. Queries public Google News RSS feeds for India carbon-market, registry, policy and project coverage.
2. Keeps headline, publisher, timestamp, RSS snippet and outbound link only; it does **not** republish article text.
3. Applies deterministic India-VCM relevance scoring and noise exclusions.
4. Deduplicates syndicated headlines and groups related headlines with an `event_id`.
5. Downloads the canonical state/district gazetteer and project/entity index generated by India VCM Explorer.
6. Resolves stories to a directly mentioned project, district, state, India-wide, or unresolved geography without inventing precision.
7. Extracts direct project, developer, methodology and registry relationships.
8. Publishes the latest 90-day feed and keeps a rolling local store/archive.

## First setup

1. Copy this repository package into `github.com/ProbablyShubham/indiavcm_news` and push to `main`.
2. In **Settings → Actions → General**, allow Actions to run and ensure workflow permissions allow **Read and write permissions** (the workflow also requests `contents: write`).
3. Before the first news run, deploy the v9.2 India VCM site builder output to `indiavcm_test`; that build publishes:
   - `data/reference/india_news_gazetteer.json`
   - `data/reference/news_entity_index.json`
4. Open **Actions → Update India VCM news feed → Run workflow** once manually.
5. Confirm `news.json` and `news_meta.json` changed in the repository.
6. Enable GitHub Pages from the `main` branch / root. The expected public endpoint is `https://probablyshubham.github.io/indiavcm_news/`.

The dashboard also has a raw-GitHub fallback, so the feed can be tested even if Pages takes time to become available.

## Automation

The workflow runs four times daily at 00:17, 06:17, 12:17 and 18:17 UTC and commits feed changes back to `main`.

## No API keys required

The initial implementation uses public RSS and deterministic classification. `sources.yml`, `terms.yml`, aliases and source weights are plain configuration files and can be reviewed/edited in GitHub.

## Reference synchronization

The workflow tries reference bundles in this order:

1. `https://indiavcm.com/data/reference/`
2. `https://probablyshubham.github.io/indiavcm_test/data/reference/`
3. last working reference cached in this repository
4. minimal repository fallback

Set `VCM_REFERENCE_BASES` (semicolon-separated) in the workflow/environment if you want another order.
